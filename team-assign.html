팀 자동 배정 대시보드

신청 마감(11/14) 후 이 페이지에서 팀 → 게임 순서로 배정합니다. 같이 온 가족·미얀마 친구는 반드시 같은 팀, 게임 배정에서는 어른끼리·어린이끼리 같은 경기로 묶입니다. 늦게 온 추가 신청은 기존 배정을 그대로 둔 채 새 사람만 배정됩니다.

전체 순서 — 이것만 기억하세요
  1. [신청자] 링크에서 신청 → 시트에 자동 기록 + 확인 메일(비밀번호·수정 링크) 발송
  2. [한인회 · 11/14 마감 후] 시트에서 신청 행 전체를 복사(헤더 행 제외) → 붙여넣기 → 자동 배정 실행 (팀) → 게임 배정 실행
  3. [추가 접수가 오면] 시트의 행을 통째로 다시 복사해 아래 추가 신청 박스에 붙여넣고 추가 인원만 배정 — 기존 접수번호는 자동 제외되고, 수정된 신청(수정일시가 바뀐 행)은 자동으로 찾아 그 가족만 다시 배정합니다. 중복 삭제 같은 수동 작업은 없습니다
  4. 배정표는 팀 배정표 복사 · 게임 배정표 복사 · CSV 내려받기로 공지·보관

전체 신청 붙여넣기

【2026 한마음 큰 잔치 참가 신청】 블록(메일·Viber 텍스트)과 구글 시트에서 복사한 행(탭 구분) 모두 붙여넣을 수 있습니다 — 형식을 자동으로 알아봅니다.

추가 신청 (늦게 온 접수)

시트에서 신청 행을 통째로 다시 복사해 붙여넣으세요 — 이미 배정된 접수번호는 자동으로 제외되고(중복 걱정 없음), 새 사람만 팀·경기에 배정됩니다. 기존 사람들의 배정은 그대로 유지됩니다.

게임별 자동 배정

정원·연령 적합(1인 최대 3종목) 기준, 같은 신청의 어른끼리·어린이끼리는 항상 같은 경기입니다. 줄다리기는 3판제(어른전 30vs30 → 어린이전 30vs30 → 꿈의 대결 전원)로 진행 — 어른전·어린이전은 배정, 꿈의 대결은 전원. 박 터뜨리기는 전원 경기입니다. 모자라는 경기는 현장 모집으로 채우면 됩니다.

게임 정원 조정 (선택)

정원·어린이 슬롯·어린이 나이 범위(최소~최대)를 바꾸고 게임 전체 다시 배정을 누르면 새 기준으로 다시 나눠집니다. 기본 나이 제한: 슬리퍼 멀리 차기 = 3–6세(초등 밑) 전용 · 기마전·사람 찾기 = 6세 이상 · 부활 피구·공 컬링 = 전 연령(3세 이상) · 어른 경기는 나이 무관. 줄다리기는 60명(청·백 각 30명, 나이대 다양·성별 공평) 배정 · 박 터뜨리기만 전원 참가(0)입니다.
