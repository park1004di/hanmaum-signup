신청폼 깃허브 배포 가이드

컴퓨터 지식이 없어도 5분이면 됩니다. 파일은 index.html 한 개뿐이고, 전부 무료입니다.

STEP 0 깃허브 계정 만들기 (처음이면)

github.com/signup 접속 → 이메일 입력 → 비밀번호(영문+숫자 8자 이상) → 사용자 이름(Username) 결정 → 이메일 인증

⚠︎ 이 사용자 이름이 그대로 웹 주소가 됩니다: https://사용자이름.github.io/… — 되도록 짧고 단순하게 (예: hanmaum-myanmar)

STEP 1 저장소(보관함) 만들기

로그인 후 오른쪽 위 + → New repository

Repository name: hanmaum-signup · Public 선택 → Create repository

STEP 2 index.html 업로드

저장소 화면의 "uploading an existing file" 링크 클릭 → index.html 파일을 끌어다 놓기 → Commit changes 클릭

STEP 3 웹사이트 켜기 (Pages)

저장소의 Settings → 왼쪽 메뉴 Pages

Source: Deploy from a branch · Branch: main / /(root) → Save

1~2분 뒤 주소가 생깁니다: https://본인깃허브아이디.github.io/hanmaum-signup/

STEP 4 신청 데이터를 구글 시트로 자동 적재 (권장)

접수 대장 시트는 이미 만들어져 있고, Apps Script를 5분 만에 연결하는 별도 가이드를 준비했습니다.

→ 구글 시트 자동 적재 연결 가이드 열기

연결하면 신청 1건이 시트에 한 줄씩 자동 기록됩니다(접수번호·인원·티셔츠 사이즈 포함). 팀 배정 대시보드(team-assign.html)에도 신청 내용을 그대로 붙여넣어 배정표를 만들 수 있습니다.

STEP 5 이메일로 받는 대안 (선택)

시트 연결 대신(또는 추가로) 이메일 수신도 가능합니다 — index.html의 var OWNER_EMAIL = "";에 이메일을 넣고, 첫 테스트 신청 때 오는 FormSubmit 확인 메일의 Activate 버튼을 한 번 누르면 됩니다.

STEP 6 연결 전에도 신청은 받을 수 있습니다

이메일·시트 연결 전에는 신청자에게 "내용 복사" 버튼이 나타납니다 — 복사한 내용을 Viber·메신저로 보내주는 방식이라, 연결 전에도 링크를 공유해 신청을 받을 수 있습니다.

STEP 7 같이 올리면 좋은 파일들

team-assign.html(팀·게임 자동 배정, 운영자용) · sheet-connect.html(시트 연결 가이드) · edit.html(신청 내용 수정 페이지)을 같은 저장소에 올리면 주소 뒤에 파일명만 붙여 접속됩니다. 운영자 도구는 주소를 담당자끼리만 공유하세요. team-assign.html에는 비밀번호 화면이 있고(기본값 hanmaum1128), 바꾸려면 파일 안의 OP_PW 한 줄만 고치면 됩니다.

STEP 8 공유

생성된 주소를 Viber·카페·포스터 QR에 그대로 공유하면 끝. 수정할 때는 저장소에서 index.html을 클릭 → 연필 아이콘 → 고치고 Commit하면 즉시 반영됩니다.

자주 묻는 질문

신청자도 깃허브 계정이 필요한가요? — 아닙니다. 링크만 열면 바로 신청합니다(로그인·설치 없음). 계정은 주최측 관리용으로만 씁니다.

비용은? — GitHub Pages·Google Apps Script·시트 모두 무료입니다.

접수 현황은 어디서? — 시트 연결 시 '신청 접수 대장' 시트에서, 이메일 수신 시 메일함에서 확인합니다.

미얀마에서 구글폼이 안 되는데? — 이 페이지는 깃허브 호스팅이라 구글과 무관하게 접속되고, 시트 기록은 주최측(대한측) 연결 작업이라 신청자는 구글에 접속할 필요가 없습니다.
