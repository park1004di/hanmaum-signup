SHEET CONNECT · 구글 시트 자동 적재

신청이 구글 시트로 자동으로 쌓이게 하기

무료(Google Apps Script)이고, 설정은 딱 한 번 — 아래 순서대로 5분이면 됩니다.

STEP 1 접수 대장 시트는 이미 만들어 두었습니다

아래 링크를 열어 확인하세요 — 헤더 13칸(접수일시 · 접수번호 · 신청자 · 이메일 · 연락처 · 어른 · 어린이 · 합계 · 한인회비 · 참가자 명단 · 비밀번호(해시) · 참가자데이터 · 수정일시)이 준비되어 있습니다.

↗ 2026 한마음 큰 잔치 — 신청 접수 대장 열기

STEP 2 시트 화면에서 Apps Script 열기

위 시트에서 메뉴 확장 프로그램(Extensions) → Apps Script를 클릭합니다. (스크립트 화면이 새 탭에서 열립니다)

STEP 3 아래 코드 전체를 붙여넣기

기본으로 적혀 있는 function myFunction() { } 등을 지우고, 아래 코드를 통째로 붙여넣은 뒤 저장(💾)하세요. 시트 ID는 이미 채워져 있습니다.



  
STEP 4 배포 → 웹 앱

    
오른쪽 위 배포 → 새 배포 → 톱니바퀴 아이콘에서 웹 앱 선택

    
· 다음 계정으로 실행: 나 (본인 계정)

       · 액세스 권한이 있는 사용자: 모든 사용자 ← 중요!

    
배포 클릭 → 처음 한 번 본인 계정 승인(「고급 → 이동(안전하지 않음)」이 나와도 본인이 만든 앱이라 안전) →
    웹 앱 URL(…/exec 로 끝남)을 복사


  
STEP 5 신청폼에 URL 붙여넣기

    
index.html을 열어 이 한 줄을 찾고 (위쪽에 있습니다):

    
var SHEET_URL = "";

    
복사한 웹 앱 URL을 넣어 저장(커밋)합니다:

    
var SHEET_URL = "https://script.google.com/macros/s/AKfy…/exec";


  
STEP 6 접수 확인 메일 + 수정 페이지 켜기

    
같은 폴더의 edit.html(수정 페이지)을 신청폼과 같은 저장소에 함께 올리고:

    
· index.html — var SHEET_URL에 웹 앱 URL (이메일 주소·비밀번호 필드는 이미 있음)

       · edit.html — 상단 var SHEET_URL에 같은 URL

    
그러면 신청하신 분에게 접수 확인 메일이 자동 발송됩니다 — 접수번호·인원·명단과 함께
    비밀번호와 수정 페이지 링크가 들어가고, 신청자는 그 메일의 주소로 이메일+비밀번호 로그인 후 본인 신청을 직접 수정합니다
    (이름·나이·티셔츠 사이즈 · 수정 시 시트에 수정일시가 기록됩니다).

    
※ 개인 Gmail 기준 하루 약 100통 무료 발송 한도 — 초과해도 시트 기록은 항상 유지되고, 워크스페이스 계정이면 한도가 더 넓습니다.


  
STEP 6-확인 테스트

    
신청폼에서 실제로 1건 신청 → 완료 화면의 접수번호와 시트에 쌓인 행의 접수번호가 같은지 확인하세요. 이후 신청은 전부 자동 적재됩니다.


  
STEP 7 (선택) 신청자가 시트에 직접 붙여넣게 하기 — 전달 단계 생략

    
Apps Script 연결 없이 운영하려면: 시트에서 공유 → 일반 액세스 "링크가 있는 모든 사용자 · 편집자"로 바꾸고, 그 링크를 index.html의 var SHEET_LINK = "";에 넣으세요.

    
그러면 신청 완료 화면에 "시트용 내용 복사" 버튼 + "접수 대장 시트 열기"가 나타나, 신청자가 스스로 대장에 한 줄을 붙여넣습니다 — Viber로 보낼 필요가 없어집니다. (붙여넣기 형식은 대장 헤더와 같은 13칸)

    
단, 편집자 공유는 누구나 지울 수도 있으니 주 1회 파일 → 사본 만들기로 백업하고, 가능하면 위의 자동 적재(STEP 2~6)와 함께 쓰세요.


  
보안 열쇠(SECRET)는 기본값 hanmaum2026 — 바꾸실 경우 index.html의 SECRET과 앱스크립트의 SECRET을 똑같이 바꿔야 합니다.


  

    
자주 묻는 질문

    
스승인(승인) 화면이 무섭게 보이는데요? — 본인이 만든 앱이라 안전합니다. 「고급」 → 「(안전하지 않은 페이지로) 이동」 → 본인 계정 선택 → 허용. 처음 1회만 나옵니다.

    
비용은? — Google Apps Script·시트 모두 무료입니다. 일일 할당량도 행사 규모(수백 건)에서는 넉넉합니다.

    
여러 명이 접수 현황을 봐야 하면? — 시트 오른쪽 위 공유로 담당자 이메일을 추가하면 같은 대장을 같이 봅니다.

    
신청폼에서 전송 실패가 나오면? — URL이 /exec로 끝나는지, 액세스 권한이 '모든 사용자'인지 확인하세요. 그래도 안 되면 신청자 화면에 '내용 복사' 안내가 뜨므로 접수가 막히지는 않습니다.
